◆ DispatchAction() [1/2]

void ACreatureInteraction< TParams >.DispatchAction ( CreatureData participant,
DriverActionDefinition action,
float timerSeconds )
inlineprotectedinherited

Dispatches a DriverActionDefinition to a participant, while also enforcing a maximum execution duration.

The participant is marked as busy until either:

  • The action's own completion condition succeeds.
  • timerSeconds seconds have elapsed.

Internally, both conditions are combined using AnyOf(Func<bool>[]) so whichever completes first will finish the action.

Once completed:

  • CreatureInteractionState.ActionComplete is set.
  • CreatureInteractionState.ActionIndex is incremented.

This method is intended to be called from UpdateInteraction(CreatureData,float) implementations.

Parameters
participantParticipant that will execute the action.
actionAction definition to execute.
timerSecondsMaximum number of seconds the action may run before it is forcibly considered complete.

Func< bool > completionConditionOverride = null )

Dispatches a DriverActionDefinition to a participant.

The participant is marked as busy until the completion condition evaluates to true.

Once completed:

  • CreatureInteractionState.ActionComplete is set.
  • CreatureInteractionState.ActionIndex is incremented.

By default, the action's own completion condition is used, but it may be overridden for this specific dispatch.

This method is intended to be called from UpdateInteraction(CreatureData,float) implementations.

Parameters
participantParticipant that will execute the action.
actionAction definition to execute.
completionConditionOverrideOptional completion condition used instead of DriverActionDefinition.CompletionCondition.

◆ IsSynchronizedAction()

virtual bool ACreatureInteraction< TParams >.IsSynchronizedAction ( int actionIndex)
inlineprotectedvirtualinherited

Defines synchronization barriers within the interaction flow.



When true is returned for an action index, participants reaching that action will wait until every other participant has reached the same action before continuing.

Override this to coordinate multi-creature interactions.

Example:
Action 0 -> Everyone moves
Action 1 -> Synchronization barrier
Action 2 -> Everyone starts dancing simultaneously

Parameters
actionIndexAction index being evaluated.

Advances the interaction by one frame.

Each participant progresses independently through:

  1. InteractionPhase.Join
  2. InteractionPhase.Update
  3. InteractionPhase.Leave

Action execution only occurs while CreatureInteractionState.ActionComplete is true.
